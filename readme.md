### Tutorial improvement

Although I have read and watched some provided tutorials, I cannot remember anything
that could be improved. I have one suggestion about the book though. 

When the parametric form of the line was explained in Chapter 4.1.6, I did not
get an understanding about the difference between this form and the one I learned 
in school ($y = kx + b$). I think this distinction is important, and I would suggest
to include it in the chapter.

P.S. As it was later explained in the lecture, $y = kx + b$ could not be used,
because there is no way to distinguish between the points lying on $x = 0$ axis.
